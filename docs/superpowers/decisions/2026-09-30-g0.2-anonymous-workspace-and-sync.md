## Context

GeoNexo must work offline without a login screen, then synchronize through a server-side capability scoped to one anonymous workspace. Contract and schema feasibility is G0.2; runtime authentication, database isolation, synchronization, and blobs are downstream implementation and QA tasks. The contract review must freeze one wire model without implying those controls already exist.

## Decisions

1. **Anonymous workspace capability.** The installation UUID is metadata and never authorizes access. A bearer and raw bootstrap proof use the canonical unpadded base64url representation of exactly 32 bytes. The client/server runtime must create the bytes with a cryptographically secure random source. The server stores only digests, verifies secrets in constant time, and enforces generation, recovery, and revocation transactionally.
2. **One synchronized domain.** `SyncEntity` is `project | map | layer | feature | import`. Payload projections are strict and canonical; layer style/metadata JSON is bounded. Feature geometries contain at most 10,000 coordinate positions. The runtime rejects request bodies over 1 MiB before JSON parsing and applies geometry bounds before database work.
3. **Immutable, replay-safe sync envelopes.** Push operations carry operation IDs, base versions and optional predecessor IDs. Upserts require payload entity/ID agreement; deletes carry no payload. Responses preserve durable version/sequence for replay. Runtime must hash canonical envelopes, validate predecessor workspace/entity/cycles, lock sequence allocation, and commit entity/tombstone/receipt/sequence atomically.
4. **Opaque workspace-bound cursor.** The wire value is `v1.<base64url-payload>.<base64url-HMAC-SHA256>`. The payload contains the workspace and committed sequence. Pull middleware validates the MAC and capability-workspace binding before querying; the repository receives only server-derived workspace and internal sequence. The Zod schema checks token syntax only.
5. **Non-disclosing scope conflict.** `SCOPE_REJECTED` uses `serverVersion: 0` and omits `serverPayload`; `VERSION_CONFLICT` requires a positive server version. This avoids exposing another workspace's entity version or payload.
6. **Bounded immutable assets.** PDF `BlobRef` remains at 25 MiB with `application/pdf`. PMTiles archives use `application/vnd.pmtiles`, are bounded at 250 MiB including manifest assets, and use strict POSIX-relative asset paths with approved JSON/PBF/PNG media types. The safe `@` character is allowed in POSIX segments for MapLibre `@2x` sprites; absolute paths, backslash, colon, percent encoding, query/fragment, dot segments and traversal stay rejected. The runtime must independently verify received bytes and SHA-256 before persistence.
7. **No login or capability-sharing expansion.** No person-level identity, sharing capability, browser database credential, remote tile capture, or public provider caching is introduced by this design.

## Consequences and remaining gates

This decision closes only G0.2's shared contract/design freeze and unlocks G0.5 W0 to consume the frozen manifest. It does **not** close runtime authentication or product acceptance. CSPRNG generation, credential digest/recovery/revocation, HMAC signing/verification, capability middleware, workspace-scoped queries/transactions, idempotency receipts, predecessor checks, upload byte/hash verification, and cross-workspace HTTP tests remain unimplemented and gated under Tasks 2–9 and final quality/security review.
