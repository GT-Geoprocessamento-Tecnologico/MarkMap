# Privacidade

Este documento registra requisitos técnicos. **Não substitui uma política de privacidade pública ou revisão jurídica.**

## Dados potencialmente tratados

Conforme funcionalidades atuais, o produto pode processar:

- localização/GPS;
- geometrias desenhadas;
- projetos, mapas e camadas;
- arquivos/importações GIS e PDF;
- metadados técnicos de sincronização;
- identificadores locais de instalação/workspace.

## Princípios recomendados para a política final

- finalidade clara para localização;
- coleta mínima;
- armazenamento local enquanto offline;
- explicar quando ocorre sincronização;
- explicar retenção e exclusão;
- explicar tratamento de arquivos/fotos caso habilitados;
- distinguir identificadores técnicos de identidade pessoal;
- informar permissões Android/iOS;
- canal para solicitações do titular quando aplicável.

## Estado

A política pública específica para localização, arquivos e sincronização está **pendente** antes da distribuição pública.
