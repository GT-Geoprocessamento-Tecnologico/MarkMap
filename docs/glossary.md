# Glossário

**Capability** — token de autoridade associado a um workspace, usado para acessar sincronização sem representar identidade de usuário.

**Workspace** — escopo de isolamento lógico dos dados e operações de sincronização.

**Outbox** — fila local durável de operações ainda não confirmadas pelo servidor.

**Ack** — confirmação durável de uma operação aceita ou já aplicada.

**Tombstone** — registro de exclusão usado para propagar remoções durante pull incremental.

**Cursor** — marcador opaco do ponto de leitura do sync remoto.

**IndexedDB** — banco local do navegador usado como fonte operacional no dispositivo.

**PostGIS** — extensão geoespacial do PostgreSQL usada no backend remoto.

**SIRGAS 2000 / EPSG:4674** — sistema de referência canônico usado pelas geometrias persistidas.

**GeoPDF** — PDF contendo informação de georreferenciamento utilizável para posicionamento cartográfico.

**PWA** — aplicação web instalável com recursos offline.

**Capacitor** — ponte usada para empacotar o mesmo núcleo web em Android/iOS.
