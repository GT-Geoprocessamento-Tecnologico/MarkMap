## 2024-10-23 - Add Icon and Loading State to Export Button

**Learning:** Adding a relevant icon (like a download symbol) and a loading state to action buttons provides immediate visual feedback, making the UI feel more responsive and intuitive.
**Action:** When adding or modifying action buttons, check if an icon or a loading state indicator would improve the user's understanding of the button's function and status. Use the existing `AppIcon` component for consistency.
